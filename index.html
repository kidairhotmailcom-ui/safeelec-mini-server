📥 คู่มือติดตั้งโค้ดลง ESP32

  1. เปิด Arduino IDE → ติดตั้งบอร์ด ESP32 (Additional Boards Manager URLs: https://dl.espressif.com/dl/package_esp32_index.json)
  2. เลือกบอร์ด: ESP32 Dev Module
  3. ก๊อปโค้ด ESP32 ด้านล่าง → วางในหน้าต่าง
  4. แก้ไขชื่อ Wi-Fi, รหัสผ่าน, หมายเลขห้อง และ URL เซิร์ฟเวอร์
  5. กดอัปโหลด ➡️ เสร็จสิ้น!
